# OpenRouter 与 OpenAI chat completions 的 wire 差异（事实记录）

> 只记事实：字段名、形状、出处。「信谁」「怎么映射」不在本文讨论。
> 出处：
> - OpenRouter 官方 OpenAPI：`https://openrouter.ai/openapi.json`
>   （抓取于 2026-11-21，含 `ChatRequest` / `ChatResult` / `ReasoningDetailUnion` /
>   `ChatUsage` / `Model` 等 schema）；
> - 官方模型目录：`GET https://openrouter.ai/api/v1/models`（同日抓取，476 条）；
> - 官方文档页：Errors and Debugging（`docs/api-reference/errors`）、
>   Limits（`docs/api-reference/limits`）、Reasoning Tokens
>   （`docs/guides/best-practices/reasoning-tokens`）；
> - Zed `crates/open_router/src/open_router.rs`（commit `4ed72e0135`）：
>   复用 `open_ai::stream_chat_completion`，只加 header / 错误体 / `/models/user`。

## 1. 端点与分帧

| | OpenAI | OpenRouter |
|---|---|---|
| 对话路径 | `POST {base}/chat/completions` | 同形：`POST {base}/chat/completions`（`base` = `https://openrouter.ai/api/v1`） |
| 模型列表 | `GET {base}/models`（需鉴权） | `GET {base}/models`（**公开**，不带密钥也能读） |
| 流式分帧 | SSE `data: {...}\n\n` + `data: [DONE]` | 同形（SSE + `[DONE]`） |
| 归因 header | 无 | `HTTP-Referer`（应用主页）、`X-Title`（应用名），可选 |
| 其他 header | 无 | `X-OpenRouter-Metadata: enabled` 才回路由元数据（默认关） |

OpenRouter 文档没有把 `HTTP-Referer` / `X-Title` 写成必需；Zed 只在设置里
给了 `app_url` 时才发 `HTTP-Referer`（`crates/open_router/src/open_router.rs`）。

## 2. 请求字段

| canonical | OpenAI | OpenRouter |
|---|---|---|
| 思考强度 | 顶层 `reasoning_effort`（o 系列） | **`reasoning: { effort }`**；另有顶层简写 `reasoning_effort`（不能与 `reasoning.effort` 冲突） |
| 思考预算 | 无 | `reasoning.max_tokens`（Anthropic/Gemini/Qwen 风格） |
| 思考开关 | 无 | `reasoning.enabled`（默认由 effort / max_tokens 推断） |
| 不回传思考 | 无 | `reasoning.exclude: true`（仅 Chat Completions） |
| 思考回放 | 无 | assistant 消息可带 `reasoning`（字符串）或 `reasoning_details`（数组） |
| `stream_options` | `{include_usage: true}` 才回 usage | **字段存在但已废弃、无效果**；流式始终回完整 usage |
| 输出上限 | `max_tokens` / `max_completion_tokens` | 两者共用同一预算；`max_tokens` 在 schema 里标 deprecated |
| 路由偏好 | 无 | `provider: {...}`（排序、过滤、回退） |
| 会话粘性 | 无 | `session_id`（≤256 字符，粘同一上游以命中 prompt cache） |
| prompt cache | `prompt_cache_key` | 同名；另有 `prompt_cache_key` 在 schema 里是 `string|null` |
| `service_tier` | `auto`/`default`/`flex`/`scale`/`priority` | 另一套取值（`fast`/`priority`/`flex` …），不与 OpenAI 枚举同集 |
| `stop` | `string` 或数组 | `string` 或数组（**最多 4 个**） |
| 结构化输出 | `response_format` 三种 | 同三种 + `grammar` / `python`（OpenRouter 扩展） |
| 图片 | `image_url.url`（URL 或 `data:`） | 同形 |
| 工具定义 / 调用 | `tools[].function.{name,description,parameters}`；`arguments` 是 JSON 字符串 | 同形 |
| 工具结果 | `role:"tool"` + `tool_call_id` | 同形 |
| 其他采样 | `top_p` / `seed` / `logprobs` / `n` / penalties | 也有；本库的 canonical 请求不表达这些 |

`reasoning.effort` 的取值：`max` / `xhigh` / `high` / `medium` / `low` /
`minimal` / `none`（`x-speakeasy-unknown-values: allow`）。

### 思考回放的原文规则（Reasoning Tokens 文档）

- `message.reasoning`（字符串）与 `message.reasoning_details`（数组）二选一，
  也可以都用；`reasoning_content` 是 `reasoning` 的别名，「functions identically」。
- 「When providing reasoning_details blocks, the entire sequence of consecutive
  reasoning blocks must match the outputs generated by the model during the
  original request; you cannot rearrange or modify the sequence of these blocks.」
- 回放主要服务于工具调用：模型暂停输出、等工具结果，然后「continue building
  that existing response」。

`reasoning_details[]` 的联合类型（`ReasoningDetailUnion`，按 `type` 区分）：

| `type` | 字段 |
|---|---|
| `reasoning.text` | `text`、`signature`、`format`、`id`、`index` |
| `reasoning.summary` | `summary`、`format`、`id`、`index` |
| `reasoning.encrypted` | `data`、`format`、`id`、`index` |
| `reasoning.server_tool_call` | `tool_name`、`arguments`、`result`、`tool_call_id`、`id`、`index` |

`format` 是枚举（`anthropic-claude-v1` / `google-gemini-v1` /
`openai-responses-v1` / …），文档要求回放时原样保留。

## 3. 响应字段

| | OpenAI | OpenRouter |
|---|---|---|
| 文本 / 工具调用 | `choices[].message.{content,tool_calls}` | 同形 |
| 纯文本思考 | 无官方字段 | `choices[].message.reasoning`（+ 别名 `reasoning_content`） |
| 结构化思考 | 无 | `choices[].message.reasoning_details[]`（同上表） |
| 拒绝 | `message.refusal`（新字段） | 同形；`finish_reason` 可为 `content_filter` |
| 结束原因 | `stop` / `length` / `tool_calls` / `content_filter` | 同 + **`error`** |
| usage | `{prompt_tokens,completion_tokens,total_tokens}` | 同 + `cost`、`cost_details`、`is_byok`、`*_tokens_details`、`server_tool_use_details` |
| 流式 usage | 仅 `stream_options.include_usage` 时 | **始终**在最后一帧给完整 usage |

`finish_reason` 的 schema 枚举：`tool_calls` / `stop` / `length` /
`content_filter` / `error` / `null`。

## 4. 错误体

非 2xx（官方 Errors 文档）：

```json
{"error": {"code": 429, "message": "Rate limit exceeded", "metadata": {"error_type": "rate_limit_exceeded"}}}
```

- `code` 是**数字**（HTTP 状态码），OpenAI 是字符串；
- `metadata` 是开放对象；稳定字段是 `error_type`（见下）、`provider_code`
  （实测上游限流时字段名是 `provider_error_code`），以及预算类的
  `limit_source` / `resolved_at` 等；
- 上游 provider 限流时 `message` 只是通用的 `"Provider returned error"`，真正原因
  在 `metadata.raw`，并带 `provider_name` / `is_byok` / `remedy_hint`：

```json
{"error":{"message":"Provider returned error","code":429,"metadata":{
  "raw":"google/gemma-4-31b-it:free is temporarily rate-limited upstream. ...",
  "provider_name":"Google AI Studio","is_byok":false,
  "provider_error_code":"429","limit_source":"upstream_provider_shared_pool",
  "remedy_hint":"Retry shortly, add your own provider key ..."}}}
```

- HTTP status 与 `error.code` 相同。

生成中途失败时 HTTP 已经是 `200`，错误出现在 body 里：

- 非流式：body 只有 `{"error": {...}}`、没有 `choices`；或错误挂在
  `choices[0].error` 上，可能同时带部分 `message.content`；
- 流式：一帧 `data: {...}`，**顶层** `error` + `choices[{finish_reason:"error"}]`，
  之后流终止。

`error_type` 的稳定取值（节选）：`context_length_exceeded`、`max_tokens_exceeded`、
`authentication`、`permission_denied`、`payment_required`、
`rate_limit_exceeded`、`provider_overloaded`、`provider_unavailable`、
`invalid_request`、`not_found`、`content_policy_violation`、`refusal`、
`server`、`timeout`、`unmapped`。

### 重试提示

- 429 / 503，以及 `metadata.limit_source = openrouter_in_flight_budget` 的 402，
  可能带 `Retry-After`（秒）。
- 429（免费模型 / key 管理）错误响应带 `X-RateLimit-Limit` /
  `X-RateLimit-Remaining` / `X-RateLimit-Reset`；`Reset` 是 Unix 毫秒。
- **成功的推理响应不带 `X-RateLimit-*`**。

## 5. 免费模型与限流（Limits 文档）

| 累计购买 credits | 每分钟请求 | 每日请求 |
|---|---|---|
| < 10 | 20 | 50 |
| ≥ 10 | 20 | 1000 |

- 免费变体 = 模型 id 以 `:free` 结尾；`openrouter/free` 是动态路由别名。
- 429 可能来自 OpenRouter 平台限流，也可能来自上游 provider；上游限流时
  `error.metadata.provider_code` 带原始码，且 OpenRouter 会先自动回退其他 provider。
- 免费模型目录里 2026-11-21 有 14 个零价条目，其中 12 个 `supported_parameters`
  含 `tools`（`google/lyria-*` 是音乐生成，`openrouter/free` 是路由别名）。

## 6. 模型列表形状

`GET /api/v1/models`（公开）：

```json
{"data":[{
  "id":"google/gemma-4-31b-it:free",
  "canonical_slug":"google/gemma-4-31b-it-2026...",
  "name":"Gemma 4 31B (free)",
  "created":1790000000,
  "context_length":262144,
  "architecture":{"modality":"text+image->text","input_modalities":["text","image"],
                  "output_modalities":["text"],"tokenizer":"Other","instruct_type":null},
  "pricing":{"prompt":"0","completion":"0"},
  "top_provider":{"context_length":262144,"max_completion_tokens":8192,"is_moderated":false},
  "supported_parameters":["tools","tool_choice","response_format","reasoning",...],
  "reasoning":{"mandatory":false,"default_enabled":true},
  "endpoints":["/api/v1/chat/completions","/api/v1/responses",...]
}]}
```

- `pricing` 的 `prompt` / `completion` 是**字符串十进制数**（USD / token）；
  `"0"` 才是免费。用后缀判断免费会漂移（定价会变）。
- `context_length` 是输入 + 输出窗口；`top_provider.max_completion_tokens` 是
  上游输出上限。
- `supported_parameters` 里出现 `tools` 才表示该模型接受工具定义。
- `architecture.input_modalities` 声明图片/音频输入能力。

## 7. 本仓（aa-ai）对应

`aa_ai_openrouter`：

- `chat_completion::request`：自写 encoder。`reasoning` 只发 `{effort}`；
  不发 `stream_options`；assistant 的思考回放规则见 ADR 0012 D2。
- `chat_completion::response::StreamDecoder`：SSE 分帧；`reasoning` 文本增量与
  `reasoning_details` 增量分开处理，后者按 `index`（其次 `id`）归并、`text` /
  `summary` / `data` 拼接；`finish_reason` 先记下，等 usage 帧之后再发 `Stop`。
- 错误：`ApiError{code,message,metadata}`；`detail()` 拼上 `metadata.error_type` 与
  `metadata.raw`（上游限流的真正原因）；非 2xx、流内错误、非流式 200-body 错误
  统一成 `LlmError::ProviderRejection`（体内错误 `status` 记 200）。
- `models::ModelInfo`：`id` / `name` / `context_length` / `pricing` /
  `supported_parameters`；`is_free()` 按 pricing 数值判断。
- 未解析：`architecture`、`top_provider`、`reasoning`、`endpoints`、
  usage 的 `cost*`、`openrouter_metadata`。
