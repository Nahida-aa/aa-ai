# 验证实验

> 每个实验是一个**可独立运行的最小工程**，用来验证 ADR 里的一个假设。
> 原则：不依赖主工程、可复现、README 记录「问题 → 命令 → 输出 → 解读 → 局限」。

## 约定

- 目录名用 kebab-case，和 ADR 里的链接一致。
- 每个实验自带 `Cargo.toml`，并加空的 `[workspace]` 表，避免被根 workspace 纳入。
- 输出要贴进 README 快照；数字变化时更新快照并说明原因。
- 实验只验证**单一变量**，不要把多个假设混在一起。
